CP241 · Sorting Algorithms

Sort Master

เกมฝึกคิดแบบ Algorithm เรียงลำดับ คุณต้องเป็น Bubble Sort และ Selection Sort ด้วยตัวเอง แล้วทายว่า Algorithm ไหนจะชนะบนข้อมูลชุดไหน ทุกคำตอบถูกตรวจจากโค้ด Sorting จริงที่รันอยู่เบื้องหลัง

Insertion Sort กำลังทำงานให้ดูสดๆ

เลือกด่าน

    กติกา

    • มี 3 ด่าน เล่นตามลำดับหรือเลือกเองก็ได้ ผ่านครบทั้ง 3 ด่านจึงจบเกมและได้ระดับ (Rank)
    • ด่าน 1 และ 2: คุณคือ Algorithm ตัดสินใจทีละขั้นตามกฎ ตอบผิด 1 ครั้งเสียหัวใจ 1 ดวงและหัก 20 คะแนน หัวใจหมด 3 ดวงคือแพ้ด่านนั้น ต้องเล่นใหม่
    • ด่าน 3: ทายว่า Algorithm ไหนใช้ “ขั้นตอน” น้อยที่สุด 3 รอบ (1 ขั้นตอน = เปรียบเทียบ 1 ครั้ง หรือสลับ 1 ครั้ง) ถูกอย่างน้อย 2 รอบจึงผ่าน
    • แต่ละด่านเต็ม 100 คะแนน รวม 300 คะแนน ถ้าได้ 270 ขึ้นไปคือ Sort Master ถ้าได้ 230 ขึ้นไปคือ Sort Expert
    • คำตอบที่ถูกคือสิ่งที่ Algorithm นั้นทำจริงๆ เกมไม่ได้เก็บเฉลยไว้ล่วงหน้า แต่รันโค้ด Sorting ตรวจให้ทุกครั้ง
